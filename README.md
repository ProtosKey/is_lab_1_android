# IS Lab 1 UI

Android-клиент для бэкенда: управление городами, справочниками координат и губернаторов, специальные операции.

## Возможности
*   **Таблица городов:** пагинация, фильтрация по неполному совпадению и сортировка по любой колонке.
*   **Карточка города:** создание, просмотр со связанными объектами, редактирование и удаление.
*   **Справочники:** координаты и губернаторы; при удалении связанные города переподключаются к выбранному объекту.
*   **Специальные операции:** удаление по климату, подсчёт по высоте, поиск по подстроке, переселение населения.
*   **Живые обновления:** изменения других пользователей приходят по WebSocket.
*   **Ошибки ввода:** проверка чисел на клиенте и подсветка ошибок, которые вернул сервер.

## Технологический стек
*   **UI:** `Compose Multiplatform`, `Material 3`.
*   **Навигация:** `Voyager`.
*   **DI:** `Koin`.
*   **Сеть:** `OkHttp`, `HTTP`, `WebSocket`, сессия через `cookie`.
*   **Архитектура:** `MVVM`, `UDF`.

## Структура
*   `shared/commonMain`: общий код: `data`, модели: `MainStore`, репозитории: `RestClient`, состояния: `presentation`, экраны и компоненты: `view`, `theme`.
*   `shared/androidMain`: `OkHttpTransport` и Koin-модуль платформы.
*   `androidApp`: `AppActivity`.

## Запуск
1. Запустите бэкенд ![https://github.com/ProtosKey/is_lab1](github.com/ProtosKey/is_lab1).
2. Для сборки проекта и запуска на эмуляторе `./gradlew :androidApp:installDebug`.
3. На экране входа укажите адрес сервера. Для эмулятора по умолчанию `http://10.0.2.2:8080/is_lab_1`.
